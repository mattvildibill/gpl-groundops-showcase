These screenshots show fictional browser-simulation data, generated by the core-flow regression check. They do not show a running Java/JMS deployment.

Run the UI, then capture and verify with:

```bash
SCREENSHOT_DIR=docs/screenshots node scripts/verify-browser.mjs
```

Set `UI_URL` and `CHROMIUM_PATH` if needed. The test uses the America/Denver browser timezone to verify that mission inputs are labeled as local time.
